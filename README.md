# Сайт репетитора 

Сайт-визитка репетитора по математике. Здесь можно узнать о занятиях, посмотреть отзывы и записаться на урок.

## Технологии

- HTML, CSS, JavaScript
- React
- Vite
- Lucide React - иконки

## Что есть на сайте

- Информация о репетиторе, направлениях подготовки и стоимости.
- Галерея фотографий и отзывы с просмотром изображений.
- Адаптивная вёрстка для компьютеров и телефонов.
- Форма записи: заявка копируется в буфер обмена, после чего открывается telegram.

## Запуск проекта

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Фотографии находятся в `public/vibe`, отзывы — в `public/reviews`.

Проект сделан для портфолио.
